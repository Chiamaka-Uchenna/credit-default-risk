Fairness audit

The model was not given sex, age, education or marital status. This table checks the outcomes anyway, at a cutoff where a default costs five good accounts. The four-fifths rule asks that every group's approval rate is at least 80 percent of the highest group's.

Method and limits

  • Data: 30,000 credit card customers of a bank in Taiwan, April to September 2005, with default observed the following month (Yeh and Lien, 2009).
  • Model: gradient boosted trees with monotonic constraints, so that more late payments can never lower predicted risk. Fifteen behavioural features and no demographics.
  • Every customer in the data already held a card, so the model has not seen rejected applicants. Using it for new applications would need reject inference.
  • Default behaviour changes with the economic cycle. A production model needs out-of-time validation and regular recalibration.
